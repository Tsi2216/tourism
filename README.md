# Oromia Tourism

Oromia Tourism is a React website I built to help people explore places, culture, food and travel ideas in Oromia.

## What the project includes

- Destination cards and destination detail pages
- An interactive map of selected places in Oromia
- Search and destination filters
- Culture and history sections
- Oromo food section with source links
- Gallery for places, culture and food
- Favorites saved in the browser
- Simple trip and itinerary planning
- Responsive layout for desktop and mobile

## Run the project

```bash
npm install
npm run dev
```

For a production build:

```bash
npm run build
```

## Project structure

```text
src/
  components/    Reusable navigation and UI components
  pages/         Main website pages
  store/         Local application state
  data.js        Destination, culture and food data
  App.jsx        Application routes
  index.css      Website styles
public/images/   Local destination images
```

## Content and image notes

The project focuses on Oromia tourism and uses real place and cultural references. The three destination images supplied for this version are stored locally in `public/images/`:

- Sof Omar Cave
- Lake Langano
- Bale Mountains

Food and culture entries include source links where a public reference is available. Some other destination and video links are external, so they should be checked before the site is published.

Oromo traditions can vary between communities and regions. The information in this project is intended as a starting point for the website, not as a complete record of Oromo culture.

Before publishing the site, check the copyright and reuse conditions for every third-party photograph, video and external source.
